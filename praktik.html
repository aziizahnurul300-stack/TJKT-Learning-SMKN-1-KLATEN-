Praktik Dasar Teknik Jaringan Komputer dan Telekomunikasi

Halaman ini berisi panduan praktik dasar TJKT yang dapat dilakukan oleh siswa untuk memahami penerapan materi secara langsung.

1. Crimping Kabel UTP

Tujuan

Praktik crimping bertujuan agar siswa mampu membuat kabel jaringan UTP dengan konektor RJ45 sesuai standar T568A maupun T568B sehingga kabel dapat digunakan untuk menghubungkan perangkat jaringan.

Alat dan Bahan

  • Kabel UTP
  • Konektor RJ45
  • Tang Crimping
  • LAN Tester
  • Cutter atau Pengupas Kabel

Langkah Kerja

  1. Siapkan kabel UTP sesuai panjang yang dibutuhkan.
  2. Kupas kulit luar kabel sekitar 2–3 cm.
  3. Luruskan delapan kabel kecil di dalamnya.
  4. Susun warna kabel sesuai standar T568B atau T568A.
  5. Potong ujung kabel agar rata.
  6. Masukkan kabel ke dalam konektor RJ45 hingga seluruh kabel menyentuh ujung konektor.
  7. Jepit konektor menggunakan tang crimping sampai pin menekan kabel.
  8. Lakukan langkah yang sama pada ujung kabel lainnya.
  9. Uji hasil crimping menggunakan LAN Tester.

Hasil yang Diharapkan

Kabel UTP berhasil dibuat dengan urutan warna yang benar dan seluruh indikator pada LAN Tester menyala secara berurutan sehingga kabel siap digunakan.

2. Konfigurasi IP Address MikroTik

Tujuan

Praktik ini bertujuan agar siswa mampu memberikan alamat IP pada interface MikroTik sehingga router dapat digunakan untuk membangun jaringan komputer.

Alat dan Bahan

  • 1 Unit Router MikroTik
  • 1 Laptop atau PC
  • Aplikasi Winbox
  • Kabel UTP
  • Adaptor atau Power Supply Router

Langkah Kerja

  1. Hubungkan laptop ke router MikroTik menggunakan kabel UTP.
  2. Buka aplikasi Winbox.
  3. Pilih MAC Address router kemudian klik Connect.
  4. Setelah berhasil masuk, pilih menu IP → Addresses.
  5. Klik tombol (+) untuk menambahkan alamat IP.
  6. Masukkan alamat IP, misalnya 192.168.10.1/24.
  7. Pilih interface yang akan digunakan, misalnya ether2.
  8. Klik tombol Apply, kemudian OK.
  9. Pastikan alamat IP telah muncul pada daftar IP Address.
  10. Lakukan pengujian koneksi menggunakan perintah ping dari komputer.

Hasil yang Diharapkan

Router MikroTik berhasil memiliki alamat IP sesuai konfigurasi dan dapat diakses oleh komputer lain dalam jaringan sehingga proses komunikasi data dapat berjalan dengan baik.

Catatan

Pastikan alamat IP yang digunakan tidak sama dengan perangkat lain agar tidak terjadi konflik IP Address pada jaringan.

3. VMware

Tujuan

Praktik VMware bertujuan agar siswa mampu membuat komputer virtual (Virtual Machine) sebagai media pembelajaran instalasi sistem operasi dan simulasi jaringan tanpa harus menggunakan komputer fisik tambahan.

Alat dan Bahan

  • Laptop atau PC
  • Software VMware Workstation
  • File ISO Sistem Operasi (Windows/Linux)
  • RAM minimal 4 GB
  • Ruang penyimpanan yang cukup

Langkah Kerja

  1. Buka aplikasi VMware Workstation.
  2. Pilih menu Create a New Virtual Machine.
  3. Pilih file ISO sistem operasi yang akan digunakan.
  4. Tentukan nama Virtual Machine dan lokasi penyimpanan.
  5. Atur kapasitas hard disk virtual sesuai kebutuhan.
  6. Atur jumlah RAM dan Processor Virtual.
  7. Pilih jenis jaringan (NAT, Bridged, atau Host-Only).
  8. Klik Finish untuk membuat Virtual Machine.
  9. Jalankan Virtual Machine dengan menekan tombol Power On.
  10. Lakukan proses instalasi sistem operasi hingga selesai.

Hasil yang Diharapkan

Virtual Machine berhasil dibuat dan sistem operasi dapat berjalan dengan baik sehingga dapat digunakan sebagai media simulasi konfigurasi jaringan maupun administrasi server.

Praktikkan Ilmu yang Telah Dipelajari

Penguasaan teori akan lebih maksimal apabila disertai praktik secara langsung. Teruslah berlatih melakukan konfigurasi jaringan, instalasi perangkat, dan penggunaan software pendukung agar kemampuan di bidang TJKT semakin berkembang.
